## Connect your Copilot plan

1. Open **Settings → Providers** and choose **GitHub Copilot**.
2. If Copilot isn’t here, press **Install GitHub Copilot**.
3. Press **Sign in with GitHub**, choose **Copy code and open sign-in page**, paste the code on GitHub and approve.

Every Copilot plan works, Copilot Free included, with its own models and limits.

Conch's own tools do the work, with its approvals, skill limits and **Undo**. See [Conch's tools, through your plan](index.md#conchs-tools-through-your-plan).

## Good to know

- **Early support.** GitHub still calls its agent connection a preview.
- **Copilot's version stays steady.** Conch turns off Copilot’s own updates while it runs. **Settings → Health → Updates** offers new versions.
- **`GH_TOKEN` and `GITHUB_TOKEN` are left out.** They often hold a key Copilot would refuse.
